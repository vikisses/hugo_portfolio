## 3. Итог

На данном этапе был создан новый проект с использованием сборщика Vite. В отличие от предыдущего этапа, Bootstrap подключался не через CDN, а устанавливался внутрь проекта через npm. Это позволило собирать все файлы приложения вместе и создавать готовую production-версию проекта.

Сначала были установлены необходимые зависимости: библиотека Luxon для работы с датой и временем, Bootstrap для оформления страницы, Popper для работы компонентов Bootstrap и сборщик Vite.

Для запуска и сборки проекта в файле package.json были добавлены специальные команды:

npm run dev — запуск проекта в режиме разработки;
npm run build — создание production-сборки;
npm run preview — предварительный просмотр готовой сборки.

После выполнения команды npm run build была создана папка dist, содержащая готовую версию приложения для публикации.

Размер полученного бандла после сборки проекта:

dist/index.html — 1.34 kB;
dist/assets/index-C9vVgZsU.css — 230.09 kB;
dist/assets/index-CCc_Cld5.js — 152.02 kB.

Размер после gzip-сжатия:

HTML — 0.59 kB;
CSS — 30.71 kB;
JavaScript — 46.12 kB.

В приложении был реализован интерфейс, аналогичный предыдущему этапу. Страница состоит из трёх колонок в соотношении 2-8-2. В центральной части расположена большая красная кнопка «Показать время». При нажатии на кнопку открывается модальное окно Bootstrap, внутри которого отображается текущая дата и время, реализованные с помощью библиотеки Luxon.

В результате был создан frontend-проект с использованием Vite, Bootstrap 5 и Luxon.
